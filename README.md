# AI Generalist Lab 
The first exercise in a self-directed AI generalist course. Verifies a reproducible Python environment and a working version-control workflow.
## How to run
```
git clone https://github.com/gaurang-kai/ai-generalist-lab.git
cd ai-generalist-lab
python -m venv .venv
python -m venv .venv
.venv\Scripts\Activate.ps1        # Windows PowerShell
# source .venv/bin/activate       # Mac / Linux.
pip install -r requirements.txt
python hello.py
```
